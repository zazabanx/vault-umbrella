Research only. No code, repo, or vault was changed. Builds on `RESEARCH-OI-028.md` (first pass, same day) and uses the same collection method.

Fetched 2026-10-20, about 7:30–8:15 PM ET. View counts are what the public pages showed then; they will move.

## What this pass added

1. **Two creators the first pass skipped**, both from `vault/Posting.md` (read read-only via the GitHub connector): **The Burnt Peanut** and **bluscr3n**. `Posting.md` lists 20 creators. The other 18 match the reference-library list and were all measured in the first pass. There are no other names in it.
2. **Fresh page metadata for all 62 shorts** (51 first-pass top-3 shorts plus 11 new ones). Each `/shorts/ID` page loaded, and `ownerChannelName` matched the creator. Lengths and dates match the first pass. A few view counts went up slightly.
3. **What is on screen in each short**, which the first pass could not see: burned-in text and its casing, caption style, and facecam layout. This comes from YouTube's three auto-generated still frames per video (`i.ytimg.com/vi/ID/maxres1|2|3.jpg`, taken at about 25%, 50%, and 75% of the runtime). These are public thumbnail images, not video. I looked at them in a temporary contact sheet and deleted them afterward. No video was downloaded or saved.

### What this still cannot verify
- **The hook in the first 0–2 s (spoken or on screen).** It is still not verified for any clip. Caption tracks still return an empty body (`ip=0.0.0.0`). `get_transcript` returned HTTP 400, and player playback is `LOGIN_REQUIRED`. The earliest sampled frame is at about 25% of the runtime (4–15 s in). So `hook_text` stays blank everywhere. Text that shows up in the 25%, 50%, and 75% frames is reported as **"on-screen text seen"**, not as the hook. It counts as "persistent" only when it shows in all three frames.
- Three frames per clip cannot measure cut density, zoom, captions that only last a moment, music, or SFX. "None seen" means none in those three frames, not none in the clip.
- Per-video TikTok numbers (the `itemList` is still empty when logged out), and Twitch clip durations.
- Payoff type is an **inference** from the title plus the three frames. It is not from watching.

## Collection method (same as the first pass, plus one step)
- YouTube: `@HANDLE/shorts` → check identity (page title and header handle) → the Popular chip's continuation token → logged-out `youtubei/v1/browse` → shelf ranking. Then each `/shorts/ID` page for the exact `viewCount`, `lengthSeconds`, `publishDate`, and `ownerChannelName`. Subscriber counts come from the channel header.
- New step: still frames `maxres1/2/3.jpg` (falling back to `sd1/2/3`), center-cropped to 9:16 for viewing, then deleted.
- Twitch: Twitchmetrics search, then the exact slug's all-time clips page. TikTok: the public profile's rehydration JSON (account totals only).
- The x MCP namespace was not used. The YouTube pages already gave ranked, exact data, and X posts carry no clip length or view data that the spec needs.

## Caveats
- **No 0–2 s hook was verified for any clip.** `hook_text` is blank in the round files, per the spec.
- The frame evidence is 3 stills per clip at fixed percentages. It cannot show captions that only last a moment, the opening frame, cut density, SFX, or music. "None seen" is not "none."
- Payoff types are inferences, not from watching.
- View counts are from one day. Older shorts have had years to collect views (dates range 2021–2026).
- Big non-RL channels (Kai Cenat Live, Asmongold Shorts, Stable Ronaldo Live, Lacy) are clip channels and possibly not run by the streamer. Their style reflects an editor's format, not a live facecam over gameplay.
- Several RL top shorts are TikTok reposts (TikTok watermark visible: AlphaKep, Tenacity, bluscr3n). Their on-screen style was made for TikTok.
- bluscr3n's top is tutorials at around 0.2M views. Treat it as a layout and caption reference, not a virality reference.
- Twitch clip lengths and TikTok per-video stats are still unavailable without app credentials or a login. None were used.
- Twitchmetrics is a third-party page. The years for The Burnt Peanut's Twitch clips were not shown.
