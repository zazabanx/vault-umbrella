# New product

> Draft, not in force, until this file lives in the private umbrella repo. Delete this line when copying.

Start a product only when the user asks. This note does not create a repo.

1. Read [[Home]] and [[Preferences]].
2. Create a private git repo for the product. Do not put this umbrella inside that repo.
3. In that repo, add `vault/<Name>.md` as the home note. It starts with a bet line, then a short description, the current focus, and a "for this, read that" list:

**Bet:** We bet that <one sentence the user agrees to>. Proven when <observable result>.

The home note links every other note in that vault. Agents read the home note first, then only the job they were given.

4. Add `AGENTS.md` with a pointer to that home note. Copy the loop from [[build-loop-template]] between the stamp markers. In the umbrella repo that note is named `Templates/build-or-improve.md`. Do not keep a second full copy in a job note.
5. Add only the notes the product needs. Status, decisions, and known problems are the usual three. Daily notes and a weekly look-back stay off until the user turns them on.
6. Add one line for the product on [[Home]].
7. Open the product repo as its own Obsidian vault. This umbrella stays a second vault. Use the vault switcher.

Do not move a rule up into this umbrella until a second product has proven it.
