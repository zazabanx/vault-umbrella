# Umbrella vault

Shared Obsidian vault for all of zazabanx's products: Home, Preferences, and templates (build loop, new product with a bet line). Each product keeps its own vault in its repo and links here.

Product vaults:
- auto-clip-system/vault/

## Rules

- The `Bots/` notes are each bot's working memory, edited only through small docs-only pull requests.
- No secrets.
- Personal details stay at summary level.
- Product facts stay in each product's own vault and are linked, not copied.
- Daily notes go in `Daily/YYYY-MM-DD.md`: an index of at most 8 bullets, then `### <Bot> HH:MM ET` entries. Cap each note at 60 lines.
- `Daily/Daily.md` has one line per day.
